# Exploratory Data Analysis (EDA) – Loan Approval Dataset

## Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** using a Loan Approval dataset. The main objective is to explore the dataset, understand its structure, identify patterns and relationships between different variables, and gain meaningful insights that can help understand loan approval decisions.

##  Repository Structure

```text
EDA/
│
├── EDA.ipynb
├── loan_approved.csv
└── README.md
```

##  Dataset Description

The project uses `loan_approved.csv`, which contains information related to loan applications and their approval status.

The dataset is explored to understand applicant characteristics and identify factors that may influence loan approval.

##  Project Objectives

- Understand the dataset structure and features.
- Perform data cleaning and preprocessing.
- Identify and handle missing values.
- Analyze numerical and categorical variables.
- Explore relationships between different features.
- Identify patterns and trends in loan approval data.
- Generate meaningful insights through visualizations.

##  Technologies Used

- **Python** – Programming language.
- **Jupyter Notebook** – Interactive development environment.
- **Pandas** – Data manipulation and analysis.
- **NumPy** – Numerical operations.
- **Matplotlib** – Data visualization.
- **Seaborn** – Statistical data visualization.

##  Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shivabenni2-pixel/EDA.git
```

### 2. Navigate to the project directory

```bash
cd EDA
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open `EDA.ipynb` and run the cells sequentially.
